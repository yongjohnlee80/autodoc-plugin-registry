AutoDoc registry

AutoDB

SQL workspaces and connections in a card beside the page: run a statement, a selection or a script, with results in AutoDoc's table panel.

A plugin, autodb, by yongjohnlee80: https://github.com/yongjohnlee80/autodb

What it declares

At commit 1d71cfc20a0bb15c628aa2e54d00f21e0844f1c5:

  • a card beside the page
  • reads the open note's text (feed)
  • commands: Show or hide the AutoDB card (o on its SPC p card), Run statement or selection (r on its SPC p card), Run a query (:autodb query <sql>), Save the remote note to its server, Run whole script (s on its SPC p card), Connection… (c on its SPC p card), Cancel query (x on its SPC p card)
  • may run AutoDoc's commands: buffer.new, file.open_path, file.save, plugins.update
  • shows a table of results (Results)
  • a Lua package, asking for nothing
