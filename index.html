AutoDoc registry

Plugins, Lua packages and KB types AutoDoc can install by name. An audit is an AI model's reading of the code at one commit: advice, not a guarantee. AutoDoc always shows its risk warning. The machine-readable list is index.json.

  • AutoVim coding KB (kb-type), A coding project's KB: ADRs, conventions, playbooks, reviews, PR records and synthesis, beside the code. not audited
  • PARA (kb-type), Tiago Forte's PARA: Projects, Areas, Resources and Archives, filed by how actionable they are. not audited
  • Slip-box (kb-type), Ahrens's slip-box: one flat box of ID-named permanent notes ordered only by links, with references and project drafts beside it. not audited
  • Zettelkasten (kb-type), Luhmann's method: fleeting, literature and permanent notes, joined by links and structure notes. not audited
  • AutoDB (plugin), SQL workspaces and connections in a card beside the page: run a statement, a selection or a script, with results in AutoDoc's table panel. not audited
  • Jupyter (plugin), Run a lab note's cells (*.lab.md) in a Jupyter kernel, keep their outputs beside the note for AutoDoc to draw, and open an .ipynb as a lab note. not audited
  • AutoTetris (plugin), Tetris as a dialog over the page, drawn through AutoDoc's plugin SDK, by the guideline: a 7-bag and Super Rotation System kicks. not audited
